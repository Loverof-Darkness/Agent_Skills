# Agent_Skills

Central skill repository for my ChatGPT/Codex software-development work.

## Contents

- `gstack/` contains the mirrored gstack skill suite and its supporting instructions.
- `AGENTS.md` defines how ChatGPT/Codex should consume these skills across project repositories.
- `CHATGPT_CODEX.md` documents the portable in-app Codex workflow.
- `SKILLS_INDEX.md` lists the mirrored skills.
- `gstack/README.md`, `gstack/LICENSE`, and `gstack/NOTICE.md` preserve upstream documentation and licensing context.

## Upstream

gstack source: https://github.com/garrytan/gstack

Mirrored version: `1.91.12.0`

See `UPSTREAM.md` for the exact source snapshot and maintenance notes.

## Usage model

This repository is the central reference source. When developing another GitHub repository, select the relevant skill under `gstack/`, read its instructions and referenced support documents, then apply the workflow using the tools available in ChatGPT/Codex.

Do not claim the upstream Claude Code runtime is installed just because its instruction files are present here.
